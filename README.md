# ♻ WasteConnect - Smart Waste Exchange & Sustainability Hub

A modern MERN-style waste management platform that connects communities for sustainable waste exchange, civic reporting, and environmental awareness.

---

## 🚀 Features

- ♻ **Smart Waste Exchange** – Post and browse waste items for reuse/recycling  
- 🚛 **Recycler Dashboard** – Manage pickup requests and processing  
- 🏙 **Community Reporting** – Report civic issues and track status  
- 🔐 **User Authentication** – Role-based access (Household, Recycler, NGO, Admin)  
- 🔔 **Real-time Updates** – Notifications and request tracking  
- 📱 **Responsive UI** – Works on mobile & desktop  

---

## 🛠️ Tech Stack

### Frontend
- React 18 (Vite)
- Tailwind CSS
- Framer Motion
- React Router
- Recharts

### Backend
- Node.js
- Express.js
- MySQL (can be replaced with cloud DB)
- Multer
- CORS
